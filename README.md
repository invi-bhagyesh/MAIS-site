# MAIS site (draft)

Static front end for the [MAIS open-problem registry](https://github.com/Math-for-AI-Safety/MAIS). Plain HTML, CSS and JS, no build step.

- `index.html`, `problems.html`, `agendas.html`, `people.html`, `about.html`
- `assets/data.js`: snapshot of the registry (92 problems, 8 agendas) taken from the MAIS repository
- `assets/art.js`, `assets/site.css`, `assets/site.js`: drawings, styles, helpers

Served at `https://invi-bhagyesh.github.io/mais/` through GitHub Pages (deploy from `main`, root).
